# Sistema de Certificados EDUQ

Este é um sistema completo para emissão, verificação, listagem e análise de certificados EJA/Ensino Médio da EDUQ, com integração ao Firebase.

## Funcionalidades
- Login com Firebase Authentication
- Emissão de certificados com geração de PDF
- Consulta pública por CPF
- Listagem e busca interna de certificados
- Dashboard com gráfico de emissão
- Página inicial com menu

## Como usar
1. Configure seu Firebase e copie o firebaseConfig
2. Cole o firebaseConfig nos arquivos:
   - login.html
   - auth.js
   - painel_certificados_pdf.html
   - painel_listagem.html
   - dashboard.html
   - consulta_certificados.html
3. Suba este conteúdo em um repositório GitHub
4. Ative o GitHub Pages no menu Settings > Pages
